1 Introduction / Purpose 
The purpose of this document is to describe the instrumental setup and operational workflow 
to qualify your demo system prior to run prm-PASEF acquisitions on timsTOF Pro & timsTOF 
Flex systems. 
The gradients, files and procedures used for QC purposes can also serve as templates for 
real-life prm-PASEF acquisitions.  
 
Table 1  describes the typical times and numb er of injections required to QC your system, 
depending on your hardware setup: 
Table 1

Sensitivity / Linearity / LOD 1 75 min 1 30 min 
CV accuracy 3 225 min 3 90 min 
 
* : using a 25 cm Ion Optiks columns setup and a 30 min gradient 
** : using a Bruker Ten column with the 50 SPD method 
Several Skyline templates are used to facilitate processing while requiring minimal knowledge 
on how to handle Skyline, however it is strongly recommended to read Skyline’s introduction 
tutorial to get familiar with data handling in Skyline.

3.1 Step 1: Perform a standard PASEF acquisition  
Perform a standard PASEF acquisition, which is a data dependent acquisition approach, on 
the Hela + isotopolog QC sample (1 µl injected) to create the Skyline library and populate the 
prm-PASEF target list for both isotopolog targets and the background Hela targets.  
You typically need to perform this step only once. Once this has been done, the correction for 
a potential retention time shift can be performed in Skyline as described in 3.1.g. 
a. Use the same  gradient as the one you intend to use (you can use the associated 
method). 
b. Use the appropriated PASEF method to measure your sample. Make sure that both 
mass and ion mobility ranges are properly calibrated. 
c. Once the acquisition is per formed, perform a database search with a database that 
contains your target sequences. For the 7x5 isotopolog mix, you can use the 7X5 with 
HELA.fasta file provided. 
You need to select the following modifications to be able to detect all forms of the 7 x5 
mix. The [13C3 15N1 (A,S)], [13C5 15N1 (P,V)], [13C6 15N1 (I,L)], [13C6 15N2 (K)], 
[13C6 15N4 (R)], [13C2 15N1 (G)] and [13C9 15N1 (F,Y)] must be defined in the search 
engine if not readily available.

3.3 Step 3: Adjust the prm-PASEF method for better performance 
You can improve the method’s selectivity by restricting the range of mobilities to the range of 
mobilities covered by your targets. I f you do so, do not forget to re -calibrate your acquisition 
method in the IM dimension. 
The mobility of targeted compounds ranges from 0.76 - 1.56 1/K0 in our example. Therefore, 
the mobility range of the prm -PASEF method could be narrowed from standard 0.6 0 - 1.60 
1/K0 to 0.74 - 1.60 1/K0. 
If you decide to do so, calibrate the ion mobility first. Then repeat the export of prmsqlite 
template (pages 22, 23), generate method in Skyline (page 24) and import new prmsqlite 
method to timsControl (page 26). If you omit to do so, the IM selection windows will not match 
with the modified tims cell compounds release time. 
You can also decide to adjust collision energy settings. For our ex ample, we have adjusted it 
to the following values.  
 
With regards to the tims ac cumulation time: Please be aware that increasing the tims 
accumulation time might increase sensitivity but at a cost for dynamic range. When the matrix 
is complex, we have observed signal extinction for overly-long tims accumulation times 
(> 100 ms).

3.5 Step 5: Evaluate reproducibility 
The purpose is to evaluate how reproducible the system is while acquiring many targets. The 
evaluation is done on 231 selected Hela peptides in triplicates. As the same amount of Hela 
was used in all samples with different concentration points, one could use results from different 
samples in the same measuring series to evaluate reproducibility. 
If a careful inspection and integration of all chormatographic peaks for selected Hela peptides 
were not conducted during the method creation step, some of the selection windows might not 
have been optimally adjusted. Thus, some targets might not have been measured. We will 
therefore add a filtering step to evaluate the CV’s only from the compounds which have been 
correctly targeted.

in step 3.4.d.

View > Peak areas > CV Histogram window is automatically displayed. At this points 
the peptides which have not been detected might still be filtered out. 
c. Filter out the pep tides which have not been detected o r for which the fragment ratio 
does not match the library by proceeding as follows:

3.6 Step 6: Evaluate accuracy 
This step shares some similarities with section 3.4. Load the Accuracy_7X5 Skyline template 
to proceed. This template is similar to section 3.4. template but is focusing on a smaller number 
of peptides with their pre -set concentration range . You can choose to include or exclude 
concentration points from the calibration curve by simply selecting them from Skyline’s peptide 
description. This can be done with a left mouse click on the arrow which appears when you 
hover the mouse cursor over the right-hand end of every peptide sequence.
