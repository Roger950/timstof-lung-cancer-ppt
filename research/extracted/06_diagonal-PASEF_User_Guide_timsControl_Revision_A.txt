▪ How to set up a diagonal-PASEF method
8. A diagonal-PASEF quadrupole calibration needs to be performed before newly generated 
methods can be used.
a) Calibration using Background Ions
- Calibration using background ions can be done by adjusting the LC flow to 25% ACN + 0.1%FA. If it 
fails, then please try using higher %B. If issues persist it is recommended to use the "Calibration 
using a Reference List"
- For the Evosep system please select “Flow to column – 20% sol B” to perform calibration

▪ How to set up a diagonal-PASEF method
8. A diagonal-PASEF quadrupole calibration needs to be performed before newly generated 
methods can be used.
a) Calibration using Background Ions
- Calibration using background ions can be done by adjusting the LC flow to 25% ACN + 0.1%FA. If it 
fails, then please try using higher %B. If issues persist it is recommended to use the "Calibration 
using a Reference List"
- For the Evosep system please select “Flow to column – 20% sol B” to perform calibration
b) Calibration using a Reference List
- Calibration using a reference list can be done for example by infusing tune mix using ESI source.

Notes:
▪ The new scan mode "diagonal-PASEF" supports usage of non-overlapping and overlapping windows, with 
a "MIDIA-license" being required for window overlap
o To make full use of midia-PASEF, e.g. generation of DDA-like spectra from DIA runs, data needs to be 
processed via the midia-pipeline (developed by the group of S. Tenzer, launched at iHUPO 2024). All other 
software solutions are not overlap-aware
▪ Please make sure to calibrate your instrument properly (mobility, m/z and, possibly, quadrupole) as this will 
affect the acquisition results
▪ diagonal-PASEF method might need to be adapted to your sample type and/or loaded sample amount to 
ensure complete coverage of the mobility range
▪ Please perform a sanity check of the scanning quad calibration pdf report prior to acquisition
