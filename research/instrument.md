## 三页样例中原理页：可直接使用

**标题：TIMS 与 PASEF：把离子分离与碎裂安排在同一时间轴上**

- TIMS：气流推动与反向电场阻挡共同捕集离子；扫描电场后，不同淌度的离子依次释放。
- 双TIMS：前段累积离子的同时，后段进行淌度分离，衔接连续采集。
- PASEF：四极杆选择与离子释放同步，在一个TIMS ramp内连续获取多个前体的MS/MS。
- TOF：高速记录离子的飞行时间并转换为m/z，测量前体或碎片谱图。

讲解补充：TIMS负责淌度分离，四极杆负责前体选择，碰撞池产生碎片，TOF完成质量分析；PASEF的“并行”指累积与分析并行，“连续碎裂”指顺序选择多个前体，避免被理解为所有离子同时碎裂。100 ms是培训图示例，不是通用固定值。

来源：01物理12、14、16–18页；03物理2–3、6、10页。TIMS气流/电场平衡说明依据01物理14页结构图作原理归纳。TOF飞行时间说明为补充基础原理，已用[Shimadzu官方质谱分析器说明](https://www.ssi.shimadzu.com/service-support/technical-support/analysis-basics/fundamental/mass_analyzers.html)核对；相同加速电势下飞行时间与sqrt(m/z)相关。原培训01物理12页仅明确其为高速质量扫描模块，并未详细推导TOF原理。

## 建议完整汇报中的原理段大纲

1. **从LC-MS到LC-TIMS-MS**：保留时间、m/z、离子淌度与信号强度构成培训所称“4D”；强度是观测信号，并非新增分离机制。淌度为气相离子提供互补信息（01物理10页）。
2. **离子从哪里走到哪里**：LC/ESI → 双TIMS → 四极杆 → 碰撞池 → TOF。01物理12页提供结构与时间尺度；不要把某一代仪器性能数字外推到全部timsTOF型号。
3. **TIMS如何提供淌度维度**：气流与电场平衡捕集、扫描电场分离；双TIMS使累积与分离并行（01物理14–16页）。
4. **PASEF为何适配TIMS**：在离子按淌度释放时同步切换四极杆；同一ramp内获得多个MS/MS（01物理17–18页；03物理2–3、10页）。
5. **参数围绕什么权衡**：质量/淌度范围、累积与分离时间、PASEF ramps、选择阈值与重复测量、动态排除、CE及隔离宽度。先讲参数意义，再展示软件界面。

术语注意：使用“约化离子淌度倒数1/K0”，单位V·s/cm²；不要将1/K0等同于CCS。CCS可用于描述气相离子结构相关特征，但原01物理10页“化合物的物理常数”过于简化，不宜照搬为与电荷、气体、构象等条件无关的绝对属性。

## 参数意义与可引用页码

| 参数 | 科学/操作意义 | 来源：03 PDF物理页 |
|---|---|---|
| Scan Begin / Scan End | 设置MS与MS/MS关注的m/z范围；不是淌度范围 | 6 |
| 1/K0 Start / End | 设置TIMS淌度范围；图示0.60–1.60 V·s/cm² | 6 |
| Ramp time | 第二TIMS中的分离时间；图示100 ms | 6 |
| Accu. time / duty cycle | 第一TIMS的累积时间；可以解锁并设得短于ramp time。图示100 ms/100% | 6 |
| Default / Custom | Default固定斜坡斜率，Custom可编辑；改变Δ(1/K0)/ms后必须重新TIMS校准 | 6 |
| Number of PASEF ramps | 一个前体检测MS ramp之后，安排多少个MS/MS ramps；决定循环长度，需匹配色谱峰宽 | 10–12 |
| Charge Minimum / Maximum | 对可碎裂前体的严格电荷过滤；0代表未知电荷，不是零电荷离子 | 13 |
| Polygon Compound Regions | 在m/z–1/K0热图上限定前体选择区域；方法内保存；不删除原始采集数据 | 14 |
| Target Intensity | 控制低丰度前体的重复调度；提高目标值可增加重复测量、改善谱图质量，同时占用有限调度时间 | 15、23 |
| Intensity Threshold | 前体进入MS/MS队列的最低信号门槛；降低门槛不保证弱信号一定被选中 | 16、23 |
| Active Exclusion / Release after | 已采集前体在一段时间内不再被选择；可设置强度上升后重新考虑，以及m/z/淌度匹配窗口 | 17 |
| Collision Energy | CE随1/K0设置；两锚点间线性插值、范围外恒定；高级表支持分段映射 | 18–19 |
| Isolation Width | 四极杆隔离窗口随m/z设置；两锚点间插值、范围外恒定 | 20 |
| MS/MS Stepping | 交替两套参数并合并谱图，可覆盖报告离子及其他碎片；会增加循环时间 | 21–22 |

可作示例但不可直接当SOP：03物理23页举10个PASEF ramps、100 ms、中等累积时间、Target Intensity 20,000、Threshold 2,500的复杂细胞系消化物DDA例子。该页同时说明应按样本复杂度、LC梯度和分析目标调整。03物理12页提出无标记工作流每个LC峰约8个MS点的建议。应保留“培训示例”措辞。

循环时间可作概念估算：(1+MS/MS ramps数)×ramp time，加上系统开销。不要写成严格等式：03物理10页界面10个PASEF ramps显示1.17 s，03物理2页示意图为1.1 s；最终以仪器方法显示值为准。

- 实际培训仪器型号及timsControl版本未由这两份PDF确定。01物理13页是带Omnitrap的timsOmni Σ，不能与物理12页的标准通路混作同一台仪器。
- 03物理11页前两段对低丰度前体是否可跨循环重复选择的文字容易产生冲突；保留“未完成预设重复次数时仍可能在后续循环被选中”的具体描述，若讲算法细节需核对当前版本手册。
- 03物理10页界面Target Intensity为2,000，物理23页示例为20,000；并非同一个示例，不能混抄成统一推荐参数。
- 03物理21页两套参数均写为Scan#1，疑为排版笔误；应根据下一页与界面解释为scan #1/#2。
- 03物理23页高目标强度的部分中文解释不够严谨；汇报可写“更多重复测量提高谱图质量，同时减少可用于其他前体的调度时间”，不照抄“更多时间花在更高强度肽重复”的表述。
- 01物理17页12 MS/MS/100 ms、物理18页约30 MS/MS/100 ms属于不同示意性能表达；不能把单一数值写为仪器固定上限。
