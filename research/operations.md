# 操作与实验指南摘要

所有页码均为 PDF 物理页码。内容用于组会汇报，不替代对应机型的操作规程。原文中的示例参数保留适用条件。

## 软件分工与日常操作

- Configuration Editor：配置硬件，更换液相后需激活配置；HyStar 运行时仅可查看（02，p3）。
- Compass HyStar：LC Control 管理溶剂替换、柱平衡、洗针；样本序列调用 Separation Method 和 MS Method（02，p5–9、25）。timsControl 控制质谱采集与校正。
- 液相准备：培训示例 A=0.1% FA 水，B=0.1% FA 乙腈（02，p11）。更换流动相后依次溶剂替换、Extended wash、autosampler flush，有机与水各10次（p13–15）。先核对当前 LC 版本。
- 接柱前排除管末气泡，停止 direct flow 后接柱。新柱平衡两次并核对柱型号、柱温（02，p16–18）。更换柱需 MS standby、卸压、等待软件允许；质谱端拆装还需 source deactivated（p19）。
- 校正前使柱压与 TIC 稳定，校正 m/z 与 mobility；前端真空改变后需重做。164 V±1 为 timsTOF HT 示例，不能用于所有机型（02，p20–24）。
- 先 QC，确认正常后跑首针。核对样品位置、进样量、LC/MS 方法、柱信息和所需 BPS 设置；保存、Upload Sample Conditions，状态通过后 Start Sequence（02，p25）。
- 首针检查 TIC、BPC、压力与 QC 的差异。培训建议每6–8针穿插 QC 和 Blank；压力持续明显上升时停止继续进样并检查样品（02，p26）。具体合格阈值应由本机基线和实验方案确定。

## QC SOP的边界

05英文SOP为2021年Pro/fleX/SCP相关文档，采用7×5同位素肽混合物及HeLa背景，有特定柱与梯度。只用于说明“灵敏度/定量范围、重复性、准确度分别验证”，不将其配置和阈值搬成2026年所有机型的日常标准（p3–7、28–41）。例如p4的A/B配方与02 p11不同，属于不同实验方案，不应混用。该SOP p37的CV和p41准确度要求均有特定样本、峰积分及有效定量范围前提。分析软件操作不进入本轮主讲。

## 故障排查框架

| 现象 | 优先核对 | 来源 |
|---|---|---|
| 无峰/峰形异常 | 样本量与澄清度、补偿溶剂、针/注射器气泡及堵漏、流动相、柱与泵 | 09 p15 |
| 出峰延迟 | 溶剂替换、气泡、柱温、漏液、脱气机 | 09 p16 |
| 压力持续升高 | 停止追加样本，查样本颗粒及管路/柱堵塞；测堵应按对应硬件规程 | 02 p26；09 p17–18 |
| 校正或质量偏差异常 | 参考离子、信号稳定性、温度和振动，必要时联系仪器负责人 | 09 p44–45 |
| 传输效率下降 | 离子源密封、毛细管污染、碰撞气；硬件诊断由有经验人员实施 | 09 p46–51 |
| 软件连接失败 | Compass Server状态和连接配置；重置/重装不是日常首步 | 09 p52–53 |
